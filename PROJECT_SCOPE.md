# Границы MVP «СоцНавигаторAI»

**Слоган:** «Курс на результат без отклонений».

## Пользователь

Руководитель или аналитик, контролирующий портфель социальных программ.

## Ценность

СоцНавигаторAI помогает быстро определить, где программа отклоняется от ожидаемого курса, понять связь между расходованием бюджета и фактическим результатом и получить краткое аналитическое объяснение через GigaChat.

## Основной сценарий

1. Открыть дашборд.
2. Увидеть программы, которые отклоняются от ожидаемого темпа.
3. Открыть карточку программы.
4. Сравнить бюджет, получателей, KPI и ход периода.
5. Нажать «Сформировать аналитическую записку».
6. Получить краткое объяснение от GigaChat.
7. Задать уточняющий вопрос по тем же агрегированным данным.
8. Скачать аналитическую записку.

## Роль ИИ

GigaChat не вычисляет риск и не принимает решение вместо руководителя. Риск-балл рассчитывается локально прозрачными правилами. GigaChat получает рассчитанные показатели и:

- объясняет отклонения понятным управленческим языком;
- формирует короткую аналитическую записку;
- предлагает, какие данные и действия стоит проверить;
- отвечает на вопросы только в границах переданного контекста.

## Аутентификация GigaChat

В конфигурации хранится только `GIGACHAT_AUTH_KEY`. Приложение получает краткоживущий access token через OAuth API, хранит его только в памяти процесса и использует для вызова GigaChat API. Временный access token не должен сохраняться в `.env` или репозитории.

## Не входит в MVP

- персональные данные граждан;
- интеграции с государственными ИС;
- сложная ролевая модель;
- полноценное хранилище данных;
- обучение ML-модели;
- автоматические управленческие решения;
- OpenRouter и другие LLM-провайдеры.

## Следующий этап после MVP

- база данных и история изменений;
- авторизация и роли;
- подключение реальных источников;
- ML-прогноз достижения KPI;
- уведомления и расширенная отчётность.

## Критерий готовности

MVP считается готовым, если на демонстрационном CSV можно локально пройти весь основной сценарий, проверить доступность GigaChat API и получить от GigaChat аналитическую записку при наличии корректного Authorization Key.
