# СоцНавигаторAI — MVP на GigaChat

**Слоган:** «Курс на результат без отклонений».

СоцНавигаторAI — демонстрационный сервис для мониторинга и оценки социальных программ. MVP показывает управленческий дашборд, автоматически подсвечивает риск программ и использует **GigaChat** как ИИ-аналитика.

## Идея продукта

СоцНавигаторAI помогает руководителю быстро понять, какие программы идут по плану, какие требуют внимания и где уже сформировался высокий риск отклонения. Система связывает темп расходования бюджета, фактический охват получателей, KPI и ход периода, после чего GigaChat формирует краткую аналитическую записку по выбранной программе.

## Сценарий демонстрации

1. Открыть портфель социальных программ.
2. Увидеть программы с отклонениями по сроку, результату и бюджету.
3. Выбрать проблемную программу.
4. Нажать **«Сформировать аналитическую записку»**.
5. GigaChat получает только агрегированные показатели программы и формирует краткий управленческий вывод.
6. Руководитель может задать дополнительный вопрос по выбранной программе.

## Что входит в MVP

- демонстрационный CSV или загрузка своего CSV;
- общий дашборд портфеля;
- план/факт бюджета, получателей и KPI;
- прозрачный детерминированный риск-индикатор;
- карточка программы;
- аналитическая записка через GigaChat;
- вопрос к GigaChat по выбранной программе;
- проверка подключения к GigaChat API из интерфейса;
- скачивание аналитической записки;
- Dockerfile и unit-тесты.

В MVP намеренно нет полноценной БД, сложной ролевой модели, ML-прогноза и интеграций с ведомственными ИС. Цель — законченный демонстрационный пользовательский сценарий, который можно защитить и показать за один день.

## GigaChat

Для постоянной конфигурации используется только Authorization Key:

```env
GIGACHAT_AUTH_KEY=ваш_ключ_авторизации
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-2-Max
GIGACHAT_BASE_URL=https://api.giga.chat/v1
GIGACHAT_AUTH_URL=https://ngw.devices.sberbank.ru:9443/api/v2/oauth
GIGACHAT_VERIFY_SSL=false
AI_TIMEOUT_SECONDS=60
```

Схема работы:

```text
Authorization Key
        ↓
POST /api/v2/oauth
        ↓
временный access_token
        ↓
Authorization: Bearer <access_token>
        ↓
GigaChat API
```

Краткоживущий `access_token` не должен храниться в `.env` или коммититься в Git. Приложение получает его автоматически через OAuth API и использует только во время работы процесса.

## Запуск под Windows

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
# заполнить GIGACHAT_AUTH_KEY в .env
streamlit run app.py
```

Открыть: `http://localhost:8501`.

Также можно использовать подготовленный скрипт:

```powershell
.\run.ps1
```

## Как считается риск

MVP сравнивает долю прошедшего срока программы, фактическое достижение получателей и KPI, освоение бюджета и разрыв между расходованием средств и фактическим результатом.

На выходе три статуса:

- `В норме`;
- `Требует внимания`;
- `Высокий риск`.

Риск-индикатор намеренно сделан объяснимым и rule-based. GigaChat не определяет риск сам — он объясняет уже рассчитанные показатели и помогает руководителю интерпретировать ситуацию.

## Роль ИИ

GigaChat:

- формирует краткую аналитическую записку;
- объясняет отклонения управленческим языком;
- отвечает на вопросы только по переданным агрегированным данным;
- не принимает решение вместо руководителя.

ML-прогнозирование можно добавить на следующем этапе после накопления исторических данных.
